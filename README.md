# Projeto ONG - Instituto Esperança Viva

Website institucional e interativo para ONG com foco em impacto socioambiental, engajamento comunitário e transparência.

## 🚀 Sobre o Projeto

O **Instituto Esperança Viva** é uma plataforma front-end moderna criada para conectar apoiadores, voluntários e a comunidade a iniciativas de preservação ambiental, reflorestamento e desenvolvimento sustentável.

### Principais Funcionalidades
- **Simulador de Doações & Chave PIX**: Contribuição rápida e cálculo de impacto em tempo real.
- **Galeria Interativa de Projetos**: Filtros dinâmicos por área de atuação.
- **Métricas de Impacto**: Indicadores e contadores animados.
- **Portal de Transparência**: Relatórios e prestação de contas visual e acessível.
- **Formulário de Voluntariado**: Inscrição com validação em tempo real.
- **Tema Claro / Escuro (Dark Mode)**: Alternador de tema acessível e suave.

## 🛠️ Tecnologias
- **HTML5** Semântico
- **CSS3** Moderno (Design System com Variáveis CSS, Flexbox, Grid e Efeitos Glassmorphism)
- **JavaScript ES6+** Modular
- **Git & GitHub** para versionamento de código e deploy
